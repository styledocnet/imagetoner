# AudioTimeline Component

The AudioTimeline component is a flexible, multi-track audio sequencer that allows for both traditional step sequencing and XY pad note input.

## Features

- **Multiple Tracks with Independent Settings**:
  - Each track can have its own length, mode, and instrument
  - Mute/solo controls per track
  - Color-coded tracks for visual organization

- **Dual View Modes**:
  - Step sequencer timeline view (traditional grid)
  - XY pad view for tap notes with position-based parameters

- **Resizable and Flexible Layout**:
  - Masonry grid for flexible track arrangement
  - Resizable panels for customizing track heights
  - Toggle between grid and vertical layouts

- **Visual Feedback**:
  - Minimaps provide condensed overview of each track
  - Active notes highlight during playback
  - Responsive playhead cursor
